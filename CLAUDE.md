# Проверка ФИО в Excel

GUI-приложение на PySide6 для валидации и исправления русских ФИО в Excel-файлах по базе данных SQLite.

## Команды

- `make test` — запуск тестов (pytest + coverage)
- `make lint` — полная проверка (ruff, mypy, deptry, форматирование)
- `make format` — автоформатирование кода (ruff format + fix)

## Правила

- После любых изменений в коде обязательно запускай `make lint` и `make test`. Все проверки должны проходить без ошибок.
- Язык интерфейса — русский.
- Строки длиной до 120 символов (`tool.ruff.line-length`).
