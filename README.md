# Excel Personal Data Validator

Утилита с графическим интерфейсом (PySide6/Qt) для проверки ФИО (фамилия, имя, отчество) в Excel-файлах по базе данных известных имён.

Решает проблему опечаток при массовом ручном вводе данных: программа находит значения, которых нет в базе, предлагает похожие варианты для исправления и позволяет добавлять новые имена.

## Возможности

- Графический интерфейс на PySide6 (Qt) — удобен для офисных работников
- Чтение Excel-файлов с указанием столбцов для фамилии, имени и отчества
- Проверка каждого значения по SQLite базе данных (регистронезависимо)
- Нечёткий поиск похожих значений для исправления опечаток
- Интерактивный просмотр ошибок с навигацией вперёд/назад
- Импорт имён из текстовых файлов в базу данных
- Сохранение исправленного файла в копию (исходник не изменяется)
- Работает офлайн, упаковывается в один .exe через PyInstaller

## Установка

### Для пользователей

Скачайте `validator.exe` из [Releases](https://github.com/a1d4r/excel-personal-data-validator/releases) и поместите в удобную папку. База данных `names.db` создастся автоматически при первом запуске.

### Для разработчиков

```bash
git clone https://github.com/a1d4r/excel-personal-data-validator.git
cd excel-personal-data-validator
make install
make pre-commit-install
```

## Использование

### Запуск через exe

Дважды кликните `validator.exe` — откроется графический интерфейс с двумя вкладками:

- **Проверка файла** — выбор Excel-файла, настройка столбцов, запуск проверки
- **Импорт в базу** — загрузка имён из текстовых файлов

### Запуск через Python

```bash
python -m excel_personal_data_validator
```

### Графический интерфейс

**Вкладка "Проверка файла":**
1. Выберите Excel-файл (.xlsx) через кнопку "Обзор..."
2. Укажите столбцы для фамилий (A), имён (B), отчеств (C) и начальную строку
3. Нажмите "Проверить"
4. Если найдены ошибки — откроется экран просмотра с похожими вариантами из базы
5. Для каждого неизвестного значения выберите действие: заменить, ввести своё, добавить в базу или пропустить
6. Исправленный файл сохраняется как `data_checked.xlsx`

**Вкладка "Импорт в базу":**
1. Выберите текстовые файлы с фамилиями, именами, отчествами (по одному значению на строку)
2. Нажмите "Импортировать"

## Как это работает

1. Программа загружает все известные имена из SQLite базы в оперативную память для мгновенного поиска
2. Читает Excel-файл и проверяет каждое значение (фамилия, имя, отчество — отдельно)
3. Неизвестные значения группируются и показываются пользователю с вариантами похожих имён
4. Исправления записываются в копию файла (`data.xlsx` → `data_checked.xlsx`)
5. Новые имена сохраняются в базу для будущих проверок

**База данных** содержит три таблицы: фамилии, имена и отчества. Файл `names.db` создаётся рядом с программой при первом запуске и пополняется в процессе работы.

### Сборка .exe (Windows)

```bash
make build
```

Или вручную:

```bash
uv pip install pyinstaller
uv run pyinstaller --onefile --windowed --name validator --collect-data PySide6 excel_personal_data_validator/__main__.py
# Для уменьшения размера используйте make build — он исключает неиспользуемые Qt-модули
```

Готовый файл появится в папке `dist/validator.exe`. База `names.db` создаётся рядом с `.exe` при первом запуске.

Также `.exe` автоматически собирается в GitHub Actions при создании тега `v*` или ручном запуске workflow.
